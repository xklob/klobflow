Two-staff antispin and circle hand guides

- Add a solid white hand-centering dot inside each circle, with a dark outline for contrast. Centers follow guide layout and perspective calibration in Android, the companion, and browser-only practice.
- Choose One staff or Two staves in Antispin. Two-staff practice gives A and B separate labeled horizontal/vertical crosses. Cross separation moves them apart; zero overlaps them. Existing center, size, rotation, tolerance and viewing-angle calibration apply.
- Follow four moving targets: AH / AV for staff A and BH / BV for staff B. Each pair stays one staff length apart. Set B to the same or opposite cycle direction and adjust its phase offset, along with the existing speed, countdown and dot-size controls.
- Score each staff against its own cross and moving targets. All four ends must be measured for combined alignment, following and streak credit. Missing or ambiguous ends keep the targets visible and pause scoring under the existing forgiveness settings. Switching staff count stops the exercise until you start it again.
- Beat practice gives each staff its own four outer turnarounds and separate timing result. Five-second horizontal/vertical drift summaries include both staves. Manual Auto-fit uses each staff's full-cycle movement to fit center, size and cross separation; Match staff length preserves the layout.
- Update the shared tutorial and Android/browser controls, including large-text/fullscreen labels. One-staff antispin remains available and retains its existing behavior.

Validation is documented in docs/validation.md. Private Pixel recordings remain local. They provide regression coverage for existing single-staff tracking, not physical validation of the new two-staff exercise.

The APK retains package com.caleb.klobflow and the existing signing certificate, with versionCode 15. Update through Klobstore or install the APK from this release. Refresh the updated localhost companion, or extract the matching companion ZIP for browser-only practice.
